CodeQL: From Query
to finding.

Understand how CodeQL represents code, how queries find patterns and data flows, and how to investigate a result with evidence. Learn the reasoning loop before taking it to a local CodeQL workspace.

18 GUIDED LESSONS12–15 HOURSBEGINNER → INTERMEDIATE

Learn the analysis model, practice investigation decisions, then complete a local capstone using official CodeQL tools.

Start CodeQL →Browser practice teaches investigation decisions; it does not run CodeQL. Real query execution is a local practical.

What you’ll learn

  • Explain extraction, CodeQL databases, queries, and result limitations.
  • Create and inspect a database with the CodeQL CLI.
  • Read basic QL queries and use language libraries and syntax trees.
  • Reason about sources, sinks, barriers, and data-flow paths.
  • Test custom queries with positive and negative cases.
  • Review code-scanning coverage and write an evidence-based alert investigation.

Designed for

Developers, application security learners, and engineers with basic programming familiarity.

Learning approach

Short technical explanations, official GitHub documentation, evidence-check scenarios, and a practical investigation note. The browser activities do not execute arbitrary code or a CodeQL database.

Before you start

Some CLI practice is easier with Git, a terminal, and a supported language checkout. Follow current official setup documentation; tool and language support evolves.
